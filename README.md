# 游戏大厅 · 山海小游戏

21 款单文件 HTML 小游戏，外加《雷电 · 歼36电音版》特别收录，共 22 款，全部装在 `index.html` 一个文件里，打开就能玩。

## 玩法

打开 `index.html`，点任意卡片进入游戏；每款游戏左上角有「← 大厅」返回。手机优先设计，最高分存在本机浏览器里。

## 游戏清单

- 第一批 · 益智开局：一笔绘山海、曹操快跑、搬家小熊、年兽 2048、水渠工匠、数独小馆
- 第二批 · 解压排序：织锦坊、百鸟归巢、字字归位、琉璃珠串、刀工大师
- 第三批 · 山海与汉字：饕餮吞天、捉妖格、包子叠叠塔、编钟乐师、一字守城
- 第四批 · 长线耐玩：醒狮百人阵、山海除妖录、早点铺、小小菜园、山海守关
- 特别收录：雷电 · 歼36电音版

按《北京时间 App 游戏板块规划》No.10–No.30 制作，精灵图为 AI 生成后抠图内嵌，音效全部由 WebAudio 程序合成。
